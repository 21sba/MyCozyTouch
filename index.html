Collega la dashboard

La pagina legge e comanda il repository privato AutoCozyTouch con una chiave GitHub che vale solo per lui. La chiave resta salvata su questo telefono.

  1. Apri GitHub → nuova chiave (Fine-grained token).
  2. Nome a piacere, scadenza la più lunga che ti offre.
  3. Repository access: "Only select repositories" → AutoCozyTouch.
  4. Permissions → Repository permissions: Actions = Read and write, Contents = Read and write.
  5. Genera la chiave, copiala e incollala qui sotto.
